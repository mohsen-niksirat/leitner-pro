## English

### ✨ What is Readner?

A complete, professional vocabulary learning app with **FSRS algorithm** (Free Spaced Repetition Scheduler) — the most advanced spaced repetition algorithm available. Runs as a single HTML file — no installation needed, works in any browser.

### 🧠 Core Features

| Feature | Description |
|---|---|
| 🧠 **Smart Review (FSRS)** | Automatic scheduling based on your performance — 4 rating levels |
| 📖 **Vocabulary Library** | Search, filter, edit, paginate — full word management |
| 💾 **Long-term Memory** | Mastered words transfer automatically |
| 📥 **Smart Import** | Text, PDF, TXT, JSON, DOCX, Anki (.apkg), URL |
| 📄 **PDF Reader** | Real canvas rendering + text selection + translation popup |
| 🌐 **Auto Translation** | 13 languages + free dictionary API + pronunciation |
| 🎮 **Smart Quiz** | 8 modes: meaning, opposite, sentence, spelling, definition, synonym |
| 📊 **Statistics** | Performance charts, GitHub-style heatmap, XP system (9 levels) |
| ⚡ **More** | Categories, AI examples, backup/restore, CSV/Anki export, dark mode |

### 💾 Storage

- **IndexedDB** — no size limit (3000+ words tested)
- Auto-migration from localStorage
- Full backup/restore support
